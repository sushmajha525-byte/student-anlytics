# 🎓 Student Analytics System

A web-based Student Analytics System built using **Python, Flask, Pandas, and Matplotlib**. This project helps analyze student performance by calculating percentages, grades, ranks, and generating visual reports.

## 🚀 Features

* 📊 Student Performance Dashboard
* 🔍 Search Students by Name
* 🏆 Automatic Student Ranking
* 📈 Percentage Calculation
* 🎯 Grade Assignment (A+, A, B, C, Fail)
* ✅ Pass/Fail Status
* 👑 Top Student Identification
* 📥 Download Student Data as CSV
* 📉 Top 10 Students Performance Graph
* 🎨 Responsive UI with HTML & CSS

## 🛠️ Tech Stack

* Python
* Flask
* Pandas
* Matplotlib
* HTML5
* CSS3

## ▶️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/sushmajha525-byte/student-analytics.git
```

### Navigate to Project Folder

```bash
cd student-analytics
```

### Install Dependencies

```bash
pip install flask pandas matplotlib
```

### Run Application

```bash
python app.py
```

### Open Browser

```bash
http://127.0.0.1:5000
```
